# Changelog

## 0.4.0 — Smarter chart recommendations
- Rank variable pairs using transparent data-quality and semantic-name heuristics instead of always selecting the first numeric columns.
- Choose a daily, weekly, or monthly time bucket based on date span and timestamp density.
- Use the same suggested aggregation in bar-chart explanations and previews.
- Improve descriptions of association, distribution, and interpretation limits.

Scores remain heuristic rankings and have not been validated against expert judgments.
